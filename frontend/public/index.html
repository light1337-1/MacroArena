Big Data аналитика

Сайт собирает данные профиля, калькулятора, рациона и прогресса, затем сравнивает пользователя с демо-датасетом спортсменов.

Записей в анализе --

Демо-датасет спортсменов плюс данные текущего пользователя.

Полей пользователя --

Профиль, расчет, питание и прогресс.

Похожие спортсмены --

Группа для сравнения и рекомендаций.

Средняя калорийность --

Среднее значение по датасету.

Как это связано с Big Data
1. Сбор

Пользователь вводит профиль, питание, вес, спорт и цель.

2. Хранение

В демо данные лежат в localStorage, в реальном проекте они уходят в базу.

3. Анализ

JS сравнивает пользователя с большим набором похожих спортсменов.

4. Рекомендации

На основе средних значений выводятся калории, БЖУ и выводы.
