# Pages Map

## `/`
Главная страница проекта: название, описание, преимущества, кнопка старта.

## `/calculator`
Страница ввода данных спортсмена.

## `/results`
Страница результата расчета: калории, BMR, БЖУ.

## `/comparison`
Сравнение пользователя с похожими спортсменами.

## `/progress`
Контроль веса по неделям и место под график.

## `/about`
Описание проекта, аудитории, технологий и данных.

## Frontend note
На этапе до `25.05` routing реализован как секции одного статического файла `frontend/public/index.html`.
Полноценный роутинг можно добавить на этапе React-интеграции.
