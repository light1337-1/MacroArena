# Архитектура MacroArena

## 1) Слои системы
- `frontend/` — UI, формы ввода, страницы результатов, сравнение и прогресс.
- `backend/` — REST API, бизнес-правила расчета и аналитика сравнения.
- `database/` — SQL-схема и seed-данные.
- `docs/` — документация по архитектуре и контрактам.
- `infra/` — инфраструктурные шаблоны запуска (docker и т.п.).

## 2) Логическая схема
1. Пользователь вводит данные на странице калькулятора.
2. Frontend рассчитывает BMR, калории и БЖУ в браузере.
3. Результат, черновик формы и прогресс сохраняются в `localStorage`.
4. Frontend сравнивает пользователя с большим встроенным набором похожих спортсменов.
5. Сайт показывает: результат, сравнение, БЖУ-диаграмму и график прогресса.

## 3) Frontend-модули
- `frontend/public/index.html` — открываемый статический сайт.
- `frontend/public/styles.css` — адаптивный dashboard-дизайн.
- `frontend/public/app.js` — расчет калорий, БЖУ, сравнение, прогресс, canvas-графики и `localStorage`.
- `pages/`
  - `HomePage.jsx`
  - `CalculatorPage.jsx`
  - `ResultsPage.jsx`
  - `ComparisonPage.jsx`
  - `ProgressPage.jsx`
- `features/calculator` — ввод данных и валидация.
- `features/results` — карточки калорий и БЖУ.
- `features/comparison` — блок аналитики по похожим спортсменам.
- `features/progress` — динамика веса и рекомендации.
- `components/` — переиспользуемые UI-компоненты.
- `services/api` — HTTP-клиент и методы вызова API.

## 4) Backend-модули
- `modules/users` — профиль пользователя и базовые данные.
- `modules/sports` — список видов спорта.
- `modules/calculations` — BMR/калории/БЖУ.
- `modules/comparison` — поиск похожих спортсменов и агрегаты.
- `modules/progress` — еженедельный трекинг веса.
- `routes` — маршруты API.
- `validators` — проверка входных данных.
- `services` — бизнес-оркестрация.

## 5) База данных
Схема соответствует ТЗ и лежит в `database/schema.sql`.

## 6) Что включено в проект
- Структура директорий.
- Заготовки файлов модулей и страниц.
- Контракты API и SQL-схема.
- Полностью рабочий статический frontend.
- Seed-данные для таблиц `sports` и `athlete_data`.
- BMR, калории, БЖУ, сравнение и прогресс в браузере.
- Canvas-графики без внешних зависимостей.
- Рейтинг похожести спортсменов, топ-30 сравнение, диапазон, медиана и процентиль.
- Дневник питания с распознаванием простого текста и подсчетом остатка калорий/БЖУ.

## 7) Что можно улучшить после демонстрационной версии
- Реальная интеграция с БД.
- Backend API.
- Авторизация пользователей.
- Экспорт результатов.
