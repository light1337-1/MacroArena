# Отчет для защиты проекта MacroArena

## 1. Название и идея проекта

**MacroArena** — веб-сайт для спортсменов, который помогает рассчитывать дневную норму калорий, БЖУ и анализировать питание относительно похожих спортсменов.

Главная идея проекта: пользователь вводит свои параметры, sport/goal/активность, а система показывает, сколько калорий и макронутриентов ему нужно для выбранной цели.

Цели пользователя:
- сохранить текущий вес;
- набрать мышечную массу;
- снизить вес.

## 3. Архитектура проекта

Проект разделен на несколько слоев:

| Папка | Назначение |
| --- | --- |
| `frontend/` | Интерфейс сайта: страницы, формы, стили |
| `backend/` | Будущий API на Node.js/Express |
| `database/` | SQL-схема и тестовые данные |
| `docs/` | Документация проекта |
| `infra/` | Файлы для инфраструктуры, например Docker |

Такое разделение удобно, потому что frontend, backend и база данных развиваются независимо.

## 6. Как объяснить базу данных

База данных спроектирована под основные функции проекта.

Пользователь вводит данные, они сохраняются в `users`.
После расчета результат сохраняется в `calculation_results`.
Для сравнения система берет похожих спортсменов из `athlete_data`.
Для прогресса каждую неделю сохраняется новый вес в `progress`.

Связи:
- пользователь связан со спортом через `sport_id`;
- результаты расчетов связаны с пользователем через `user_id`;
- прогресс связан с пользователем через `user_id`;
- похожие спортсмены также связаны со спортом через `sport_id`.
